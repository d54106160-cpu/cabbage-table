## 專案簡介

「高麗菜桌」源自 Threads ：有人分享「吃火鍋時把蛋打在高麗菜葉上煮」的妙招爆紅，
之後網友把其他聰明、低成本又實用的生活妙招，都戲稱為「可以去坐高麗菜煮蛋那桌」。

本網站把這些妙招整理成一張宴會桌：

- 每一招是一位「賓客」，有自己的**座位編號**、**原創插畫**、**一句話困擾**、**簡短做法**、**分類標籤**與**出處**。
- 首頁是「座位表」，可以依分類標籤篩選。
- 所有內容皆以自己的話改寫，並標註原作者與原貼文連結。

## 📖 操作教學：用 AI 新增一招

這個專案的設計重點是：**任何 AI 讀完 AGENTS.md，就能做出風格一致的新頁面。**

### 步驟 1：準備新一招的資料

| 項目 | 必填 | 說明 |
|---|---|---|
| 原貼文連結 | ✅ | Threads 貼文網址 |
| 作者帳號 | ✅ | 例如 `@kurrrtwu` |
| 發文日期 | 建議 | 例如 `2024-01-14` |
| 一句描述或原貼文截圖 | ✅ | 讓 AI 理解做法；截圖不會放上網站 |

### 步驟 2：把專案交給 AI

- **聊天型 AI**（Claude、ChatGPT、Gemini 等）：把整個專案壓縮成 `cabbage-table.zip` 上傳。
  - 在 GitHub 上可以點 **Code → Download ZIP** 下載最新版本。
- **能連接 GitHub 的工具**（Claude Code、Codex、GitHub Copilot 等）：直接開啟這個 repository，AI 會自動讀到 AGENTS.md。

### 步驟 3：給 AI 一句指令

```
請先閱讀 AGENTS.md，依照第 10 節 SOP 新增第 004 位賓客，
完成後列出新增或修改了哪些檔案。

原貼文連結：https://www.threads.com/...
作者帳號：@xxxx
發文日期：2026-xx-xx
描述：（一句話，或附上截圖）
```

### 步驟 4：檢查 AI 的成果

AI 通常會新增或修改以下檔案：

| 檔案 | 動作 |
|---|---|
| `guests/004-xxx.html` | 新增：新一招的頁面 |
| `assets/img/004-xxx.svg` | 新增：新一招的插畫 |
| `index.html` | 修改：座位表多一張卡片 |
| `guests/003-xxx.html` | 修改：「下一位」連結指向新頁面 |

可對照 AGENTS.md 第 11 節的檢查清單確認，例如困擾只有一句、標籤在清單內、出處連結正確。

### 步驟 5：上傳到 GitHub

1. 進入 repository，點 **Add file → Upload files**。
2. 拖入 AI 新增或修改的檔案。**要放在正確的資料夾裡**：
   - 頁面放在 `guests/`：先點進 `guests` 資料夾，再上傳。
   - 插畫放在 `assets/img/`：先點進 `assets/img` 資料夾，再上傳。
   - `index.html` 放在最外層。
3. 同名檔案會被直接覆蓋，按 **Commit changes**。
4. 等約 1～2 分鐘，重新整理網站即可看到新賓客。
